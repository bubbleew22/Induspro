• Internal pilot: pilot oil main P line se (X plug) · External pilot: alag line se

Generator Formulas & Field Notes

• kVA = kW / PF · I = kVA×1000 / (√3·V) for 3φ
• f = P·N / 120 → N = 120·f / P (50 Hz: 1500 rpm @ P=4)
• Prime mover ≈ kW / (0.9 × 0.7457) HP — engine ko alternator se ~10% bara rakhein
• Derating: altitude >1000 m (~1%/100 m), temp >40 °C (~1%/°C)
• Voltage dip on motor start ≤ 10–15%; alternator subtransient reactance X″d matter karti hai
• Sync conditions: voltage, frequency, phase sequence, phase angle — chaaron match
• Load sharing: speed droop 3–5% (isochronous = no droop, single set ke liye)
• AVR: excitation control, ±1% voltage regulation typical
• Standby 0.8 PF rated; PF kam ho to kVA rating limit karti hai

VFD Theory (short)

• V/f constant: flux ∝ V/f — base Hz ke neeche V bhi proportionally kam (warna core saturate / over-current)
• Constant torque ≤ base Hz, constant power (field weakening) above base
• Fan/pump: T ∝ n², P ∝ n³ → quadratic V/f se 50% speed par ~87% energy saving
• Vector: stator current d-axis (flux) + q-axis (torque) mein split → 0.5 Hz par bhi 100–150% torque
• Ramp: accel time = ΔHz ÷ (Hz/s) · Regenerative braking → chopper + resistor
• DC bus: 1.35×V (400 V → ~540 V) · Faults: OC / OL / OV / stall

Transformer Formulas

• Turns ratio a = N₁/N₂ = V₁/V₂ = I₂/I₁
• EMF: E = 4.44·f·N·Φm · Φm = Bm × Ai (core area)
• Turns per volt TPV = 1 / (4.44·f·Bm·Ai)
• N₁ = V₁ × TPV · N₂ = V₂ × TPV × 1.03 (~3% drop compensate)
• I₁ = kVA×1000/V₁ · I₂ = kVA×1000/V₂
• Wire area = I / J → Ø = √(4A/π). J: small dry 2–3, oil-filled 1.5–2.5 A/mm²
• Short-circuit current Isc ≈ I_fl × 100 / %Z · Losses: Cu = I²R, core = hysteresis + eddy
• Efficiency η = kVA·PF / (kVA·PF + Pcu + Pfe)
